## 🛑 Problems Encountered

1.  **SDK Routing Instability**: The Deepgram SDK (v3 -> v4 -> v5) repeatedly changed its internal routing (e.g., `.prerecorded` vs `.rest` vs `.v1.media`), leading to `AttributeError: 'ListenClient' object has no attribute '...'`.
2.  **Deployment Caching**: Previous pushes to the `main` branch were occasionally ignored or cached by Streamlit Cloud, causing the app to run stale code (v3.1) despite local updates.
3.  **Infinite Log Loops**: A combination of `st.rerun()` and persisting audio data in the input widget caused the app to keep processing the same "bad" audio until it triggered an infinite loop of logs.
4.  **Audio Data Type Mismatch**: Passing a Streamlit `UploadedFile` object directly to the SDK caused `'UploadedFile' has no len()` errors, as the SDK expected raw bytes.
5.  **Import Errors**: Streamlit Cloud's Python environment (v3.9) had trouble resolving top-level convenience imports from the Deepgram package.
